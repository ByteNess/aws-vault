title: Shell completion
weight: 12
---

You can generate shell completions for
 - bash: `eval "$(curl -fs
   https://raw.githubusercontent.com/byteness/aws-vault/master/contrib/completions/bash/aws-vault.bash)"`
 - zsh: `eval "$(curl -fs
   https://raw.githubusercontent.com/byteness/aws-vault/master/contrib/completions/zsh/aws-vault.zsh)"`
 - fish: `eval "$(curl -fs
   https://raw.githubusercontent.com/byteness/aws-vault/master/contrib/completions/fish/aws-vault.fish)"`

Find the completion scripts at
[contrib/completions](https://github.com/ByteNess/aws-vault/tree/main/contrib/completions).
